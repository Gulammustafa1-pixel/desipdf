# Desi PDF

A modern PDF toolkit built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Included working browser tools

- Merge PDF
- Rotate PDF
- Remove PDF pages
- JPG to PDF

The UI and routes for additional tools are included and ready for their processing engines:
Split, Compress, PDF to JPG, Word to PDF, Watermark, Protect, Unlock, Page Numbers.

## Deploy

Push this folder to GitHub and import the repository into Vercel. The build command is `npm run build` and the output directory is `dist`.
